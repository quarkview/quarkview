# QuarkView

Practical resources for planning security cameras, PoE connections and local NVR recording.

## Planning resources

- [NVR storage calculator and worksheet](https://quarkview.com/knowledge-base/nvr-storage-sizing): estimate video capacity or recording days from average bitrate and recording hours.
- [PoE switch planning guide](https://quarkview.com/blogs/news/poe-switch-basics-for-security-camera-systems): check power requirements, shared budget and network design.
- [QuarkView website](https://quarkview.com): camera-system information and practical guides.

Storage results are planning estimates. Verify recorder limits, usable capacity, compatibility and actual recording for your equipment.

## Discuss a project

[Contact QuarkView](https://quarkview.com/contact) with camera quantity, recording days, coverage needs and existing equipment.

This repository introduces our resources. It does not contain camera firmware or a published software implementation.
